# n8n Workflows

This folder contains sanitized n8n workflow examples used in the WhatsApp AI Sales Agent.

## Workflow Components

* WhatsApp message handling
* Customer management
* AI Agent processing
* Product and stock lookup
* Delivery fee calculation
* RAG knowledge retrieval
* Order processing

## Security

The workflow files in this repository must not contain real API keys, credentials, customer data, or private configuration.

Credentials should be configured separately inside n8n.
